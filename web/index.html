MCP 服务

配置文件固定在 ，改完立即生效，无需重启。

远程服务需要鉴权时，在编辑里填「访问令牌」或自定义请求头；密钥可以写 ${ENV_VAR} 从系统环境变量读取。 点每一行的「工具」可以直接拉取工具列表、填参数试调用。

也可以直接对模型说「帮我接入 filesystem 这个 MCP」，它会用 mcp_add_server 自己完成配置。

关闭时（推荐）模型先用 mcp_list_tools 查工具、再用 mcp_call_tool 调用， 提示词只多几十个 token。金融、浏览器这类动辄上百个工具的 MCP，内联后提示词能到两万 token， 在 CPU 上光读入就要三分钟。

推理加速

本地 CPU 上「read 进提示词」比「吐字」贵得多，把固定前缀记下来能省掉每轮十几秒的等待。

原理：模型每轮都要把整段提示词重新算一遍注意力（prefill）。这里把算过的 KV 记住，下一轮只算新增的几十个 token。同一份前缀跨会话也能复用，所以开新对话同样很快。
